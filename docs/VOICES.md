# Voices

Kokoro-82M ships 54 voices. The voice id starts with a language letter and a gender letter (`af_heart` is **a**merican
English, **f**emale, "heart"). The window shows them by language; this list is the command-line view.

## Recommended

| Language | Voices |
|---|---|
| American English, female | `af_heart` (best), `af_bella`, `af_nicole`, `af_sarah`, `af_sky` |
| American English, male | `am_fenrir`, `am_michael`, `am_puck`, `am_onyx` |
| British English, female | `bf_emma`, `bf_isabella`, `bf_alice`, `bf_lily` |
| British English, male | `bm_fable`, `bm_george`, `bm_daniel`, `bm_lewis` |
| Spanish | `ef_dora`, `em_alex`, `em_santa` |
| French | `ff_siwis` |
| Hindi | `hf_alpha`, `hf_beta`, `hm_omega`, `hm_psi` |
| Italian | `if_sara`, `im_nicola` |
| Japanese | `jf_alpha`, `jm_kumo` |
| Portuguese | `pf_dora`, `pm_alex`, `pm_santa` |
| Mandarin Chinese | `zf_xiaoxiao`, `zf_xiaobei`, `zm_yunxi` |

English is Kokoro's strongest language; the other languages have only a few voices.

## Language letters

| Letter | Language | Code used by `speak.py -l` |
|---|---|---|
| `a` | American English | `en-us` |
| `b` | British English | `en-gb` |
| `e` | Spanish | `es` |
| `f` | French | `fr-fr` |
| `h` | Hindi | `hi` |
| `i` | Italian | `it` |
| `j` | Japanese | `ja` |
| `p` | Brazilian Portuguese | `pt-br` |
| `z` | Mandarin Chinese | `zh` |

The window picks the language from the voice automatically.
